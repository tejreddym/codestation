# Git & Version Control Station (`/stations/git`)

Implemented 2026-11-11. Scope: one new station landing, six new text-only tools, and reuse of the existing `gitignore-generator`. No repository is read, no Git process is spawned, and no network request or persistence is involved.

## Tools

| Tool ID | Name | Input | Output |
| --- | --- | --- | --- |
| `conventional-commit-builder` | Conventional Commit Builder | type, optional scope, description, optional body/footer, breaking flag and note | Formatted commit message plus review hints |
| `conventional-commit-validator` | Conventional Commit Validator | Commit message text | Parsed type/scope/description, breaking state, footers, validation errors |
| `git-command-explainer` | Git Command Explainer | One Git command | Subcommand/flags, summary, destructive-risk notes |
| `changelog-generator` | Git Changelog Generator | Pasted `git log` output (oneline or full) | Grouped Markdown changelog with Breaking Changes, commit/breaking counts |
| `gitattributes-generator` | Git Attributes Generator | Line-ending policy, binary globs, linguist globs/flag, export-ignore patterns | `.gitattributes` content and rule count |
| `git-hooks-generator` | Git Hooks Generator | Hook type, shell commands, fail-fast flag | Hook filename, shell script, install instructions |
| `gitignore-generator` | Gitignore Generator (shared) | Existing Network & DevOps tool | Unchanged; listed on the Git station without moving its canonical route |

Canonical tool routes remain `/tools/<id>`. The station route is `/stations/git`, generated by the generic `app/stations/[station]/page.tsx` boundary. The station lists 7 tools, uses the `GitBranch` mark, links to Code Generation, Network & DevOps, API, and Text, and is the 27th implemented station.

## Privacy and safety boundaries

- All six new tools are pure local transforms. There is no `fetch`, `eval`, `new Function`, DOM injection, storage, analytics, or worker requirement.
- `git-command-explainer` is explanatory only. It never implies or performs execution, and the UI and engine output repeat that no command is run and no repository is touched.
- `git-hooks-generator` emits a script as text. It does not write, chmod, or execute the hook, and it rejects command lines that start with a shebang.
- Inputs are bounded by `GIT_INPUT_LIMIT` (200,000 characters). The changelog parser accepts at most 5,000 commits; the hook generator accepts at most 200 commands of at most 500 characters each.
- `.gitattributes` patterns reject whitespace and quotes so a generated line cannot silently change meaning.

## Engines and wiring

- `lib/tools/git/commit.ts` — conventional commit build/parse and output formatting.
- `lib/tools/git/explain.ts` — quoted-argument tokenizer, subcommand/flag extraction, risk classification for `reset --hard`, `clean -f`, force pushes, `branch -D`, and `rebase`.
- `lib/tools/git/changelog.ts` — conventional-commit grouping and Markdown rendering.
- `lib/tools/git/attributes.ts` — `.gitattributes` rule assembly.
- `lib/tools/git/hooks.ts` — hook preludes, script generation, installation text.
- `lib/tools/git/limits.ts` — shared 200 KB guard.
- `config/git-tools.ts` — browser-only local contracts, defaults, keywords, and related tools.
- `components/GitStation.tsx` / `.module.css` — one accessible form per tool, copy, `.txt`/`.md`/`.sh` download, clear, visible errors.
- `config/tools.ts`, `config/stations.ts`, `components/ToolWorkspace.tsx`, `components/StationMark.tsx`, `components/StationLanding.tsx` — registry, route, icon, and notice wiring.
- `lib/webmcp/dispatcher.ts` — WebMCP execution for all six tools.

## WebMCP

All six tools are registered through the central registry and dispatched by slug with the usual optional `codestation_` prefix:

- `codestation_conventional-commit-builder` — formatted commit message text.
- `codestation_conventional-commit-validator` — JSON parse result.
- `codestation_git-command-explainer` — JSON explanation and risk notes.
- `codestation_changelog-generator` — Markdown changelog.
- `codestation_gitattributes-generator` — `.gitattributes` content.
- `codestation_git-hooks-generator` — JSON with filename, script, and install instructions.
